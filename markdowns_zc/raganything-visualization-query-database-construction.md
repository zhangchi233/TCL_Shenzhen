# RAG-Anything: 可视化、查询与数据库构建指南

`RAG-Anything` 是一个集成了多种 RAG（检索增强生成）技术的系统，支持通过可视化界面进行数据管理和智能查询。

---

## 1. 核心功能概览

| 功能模块 | 说明 | 主要工具/框架 |
| :--- | :--- | :--- |
| **知识库构建** | 支持多种文档格式解析与索引 | LightRAG / GraphRAG |
| **智能查询** | 支持简单、混合及全局向量查询 | OpenAI / VLLM API |
| **数据可视化** | 可视化知识图谱与检索结果 | Streamlit (建议) |
| **数据库管理** | 结构化管理处理后的原始数据 | SQLite / DuckDB |

---

## 2. 数据库构建 (Graph-based RAG)

构建流程通常涉及从非结构化数据到结构化图谱的转换。

### 执行步骤
1. **安装依赖**：
   ```bash
   pip install raganything
   ```
2. **初始化与索引**：
   运行示例脚本 `raganything_example.py` 来处理您的本地文件。
   - 程序会自动扫描指定目录。
   - 调用 LLM 进行实体和关系提取。
   - 生成持久化的索引文件。

---

## 3. 查询接口使用指南

`raganything` 提供了灵活的查询 API，支持不同层级的检索需求。

### 查询模式速查表
| 模式 (Mode) | 描述 | 适用场景 |
| :--- | :--- | :--- |
| `naive` | 标准向量检索 | 简单关键词匹配、基础问答 |
| `hybrid` | 向量 + 关键词混合检索 | 需要兼顾语义和确切术语的查询 |
| `local` | 基于图谱的局部邻居检索 | 探索特定实体及其直接关联 |
| `global` | 全局图谱摘要检索 | 总结性问题，如“本文档的主要观点是什么？” |

### 代码集成示例
```python
from raganything import RAGService

# 初始化集成服务
rag = RAGService(config_path="config/settings.yaml")

# 执行全局查询
response = rag.query(
    "总结该项目的主要技术栈及其优势",
    mode="global"
)
print(f"回答: {response}")
```

## 4. 可视化与监控

为了更好地理解数据分布和检索效果，您可以使用配套的可视化工具：

1. **启动 Web 界面**：
   - 运行可视化服务（如 `streamlit run app.py`）。
   - 在浏览器中查看生成的 **知识图谱 (Knowledge Graph)**。
2. **检索链路追踪**：
   - 查看检索到的具体 Chunk（文本块）及其相似度得分。
   - 分析 LLM 生成回复的参考依据。

---

## 5. 处理流程最佳实践

1. **数据清洗**：在构建索引前，确保输入文件的噪点已被过滤。
2. **参数调优**：
   - 如果显存不足，调整 `chunk_size` 和 `chunk_overlap`。
   - 生产环境下，建议将模型部署在 `vLLM` 后端以提高吞吐。
3. **性能监控**：使用 `htop` 和 `nvidia-smi` 实时监控资源占用情况。
